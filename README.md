# Quem Me Deve

Controle de parcelas de amigos. App web instalável (PWA): funciona offline e os dados ficam salvos só no celular de cada usuário. Esta versão pública não contém dados.

## Arquivos
- `index.html` – o app completo
- `manifest.webmanifest` – nome, cores e ícones para instalar
- `sw.js` – permite usar sem internet e atualizar automaticamente
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` – ícones

## Publicar (GitHub Pages, gratuito)
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.

## Atualizar
Envie o novo `index.html` (Add file → Upload files → Commit). Os celulares recebem a nova versão ao abrir o app com internet.
